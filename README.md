## 📌 1. 프로젝트 소개
- **학교 및 학과**: 서울의료보건고등학교 보건간호과
- **앱 명칭**: **AI 보건 탐구**
- **수업 주제**: 질병관리청 공공 보건 빅데이터(2019~2025)를 활용한 감염병 유행 추이 분석 및 AI 보건 튜터 융합 보건 탐구
- **수업 대상**: 서울의료보건고등학교 2학년 학생
- **디자인 테마**: 눈이 편안한 **슬릭 다크 테마(Sleek Dark Theme)** 및 화이트 사각 박스 안의 정품 학교 원형 엠블럼 배치
- **주요 기능**:
  1. **데이터 개요 및 5단계 연령 세분화**: 0-9세, 10-19세, 20-49세, 50-64세, 65세 이상 5개 연령층별 상세 통계 및 예방접종 또는 격리여부 데이터 제공
  2. **수업 실습용 개별 CSV 제공**: 학생 및 교사가 직접 업로드 실습을 할 수 있도록 5개 주요 질병(코로나19 제4급, 인플루엔자 제4급, 백일해 제2급, 홍역 제2급, 수두 제2급) 개별 CSV 파일 다운로드 기능
  3. **3대 시각화 라이브러리(Matplotlib vs Seaborn vs Plotly) 비교 탐구**:
     - **연도별** 발생 추이 분석 (2019 ~ 2025 유행 곡선)
     - **연령별** 5단계 환자 분포 분석 (누적 막대 및 통계 분포)
     - **해외 10개국별** 발생 현황 비교 (미국, 중국, 일본, 호주, 영국 등)
     - **국내 17개 시도별** 발생 현황 분석 (서울, 경기, 부산, 대구 등)
     - 3대 라이브러리(동적 웹 인터랙티브 vs 통계 그래픽스 vs 정밀 출판용) 나란히 비교
  4. **학교 집단감염 예방 시뮬레이터**: 홍역, 수두, 백일해, 코로나19, 사스, 엠폭스, 에볼라, 인플루엔자, 메르스 9종 전파 차단 모델링
  5. **AI 보건 튜터(Q&A)**: 질병 선택 시 자동 동기화되는 1:1 맞춤형 역학 리포트 및 전문 의학 문양 기반 질의응답
